# 雨霖铃

## 题意简述

给定一张无向图，每条边类型为 $0$ 或 $1$。要求构造一棵生成树，使其中恰好有 $k$ 条类型为 $0$ 的边；若不存在则输出 `no solution`。

## Hint

先判断类型 $0$ 边的数量下界，再判断上界。下界来自“先用类型 $1$ 边尽量连通后仍必须使用多少条类型 $0$ 边”。

??? note "提示"
    若先加入所有能加入的类型 $1$ 边，剩下为了连通而加入的类型 $0$ 边数量就是最少需求。

## 解法

先用 Kruskal 思想求必须使用的类型 $0$ 边数量。将类型 $1$ 边优先加入并查集，之后为了连通而加入的类型 $0$ 边记为 $Must$。若 $Must>k$，无解。

再构造答案：优先加入必要的类型 $0$ 边，并继续补充类型 $0$ 边直到数量达到 $k$；最后用类型 $1$ 边补齐生成树。若无法得到 $n-1$ 条边，则无解。

这个过程本质上是在生成树交换空间中控制类型 $0$ 边数量。先满足必要边，再补足可选边，可以保证不会因为较晚加入类型 $1$ 边破坏已经达到的 $k$ 条限制。

## 复杂度

排序两次或按类型分组后处理，时间复杂度为 $\mathcal{O}(m\log m)$，空间复杂度为 $\mathcal{O}(n+m)$。
