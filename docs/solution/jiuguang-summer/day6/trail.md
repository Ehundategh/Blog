# 迢迢寻故人

## 题目简述

在 $n\times m$ 的网格中，从 $[1,1]$ 走到 $[n,m]$，每一步可以四联通移动且允许重复经过格子。设经过数值的集合为 $S$，求 $\operatorname{mex}(S)$ 的最小值。

## 数据点 $1\sim4$

???+ note "题目描述"

    枚举答案 $k$，暂时删除所有数值为 $k$ 的格子，再判断起点与终点能否四联通。

??? success "解法"

    第一次可以绕开 $k$ 时，答案就是 $k$。此前所有更小数值都无法绕开，而路径允许重复经过格子，因此只要仍在同一连通区域中，路线可以依次经过它们。

??? abstract "复杂度分析"

    单次 BFS 为 $\mathcal{O}(nm)$，直接枚举为 $\mathcal{O}(nm(n+m))$。

## 数据点 $5\sim12$

???+ note "同值屏障"

    若同一行所有数相等，从第一行走到第 $n$ 行的任意路线都必须经过每一行；这一档的答案就是行代表值集合的 $\operatorname{mex}$。当 $\min(n,m)=1$ 时同理，必须经过整条线。

??? tip "Hint"

    一个数值是否一定出现，取决于它对应的格子能否把起点与终点分隔开。

## 正解

???+ note "障碍墙"

    固定数值 $k$，将所有值为 $k$ 的格子记为 $B_k$。把下边界与左边界合称为 $A$，把上边界与右边界合称为 $B$。若 $B_k$ 的某个八联通块同时接触 $A,B$，称它为一堵障碍墙。

??? success "关键结论"

    起点能够绕开数值 $k$ 到达终点，当且仅当不存在数值 $k$ 的障碍墙。

??? proof "证明"

    先取一条连接 $[1,1]$ 与 $[n,m]$ 的最短四联通格路 $P$。沿 $P$ 两侧的单位网格边作边界轨迹，并在四条边交于同一格点时，按“能够共点移动的非 $P$ 格子位于同一侧”唯一配对。由此得到的边界轨迹将 $A,B$ 分开；任何连接 $A,B$ 的八联通格链都必须和 $P$ 共用一个格子。

    因而障碍墙存在时，任何避开 $B_k$ 的四联通路径都会和它相交，矛盾。反过来，删除 $B_k$ 后令 $R$ 为从 $[1,1]$ 可达的格子集合。若终点不可达，取 $R$ 与其补集的边界轨迹。每条内部边界的非 $R$ 一侧都属于 $B_k$，否则这个格子也应可达。沿外框两段分别从起点走到终点，边界端点的奇偶性说明存在一条轨迹连接 $A,B$；取其非 $R$ 一侧格子，便得到一个八联通的 $B_k$ 障碍墙。

??? success "实现"

    从四条边界出发，对数值相同的格子进行八联通 DFS，并记录连通块从哪一条边界开始。若该连通块到达另一组边界，就标记该数值不能绕开。每个格子只进入一次 DFS，最后从 $0$ 开始找第一个未标记的数值。

??? abstract "复杂度分析"

    时间复杂度、空间复杂度均为 $\mathcal{O}(nm)$。
