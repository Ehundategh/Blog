# Gioush Judge Windows

解压后在当前目录打开终端：

```bat
gioush-judge-gui.cmd
gioush-judge.cmd list
gioush-judge.cmd profile --name Ehundategh --handle Ehundategh
gioush-judge.cmd run jiuguang-day2-wind main.cpp
gioush-judge.cmd export jiuguang-day2-wind --format md
```

`gioush-judge-gui.cmd` 会打开本地可视化页面，并支持本地注册、登录、评测和导出报告。

需要本机已经安装 `g++`。本工具不需要 Python。
