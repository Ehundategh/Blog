# 树上查询

## 题意简述

给定一棵按照深度优先遍历顺序编号的有根树，每个结点有正整数权值。一次询问给出 $l,r,k$，需要在 $[l,r]$ 中选择权值和至少为 $k$ 的非空连续区间，并最大化区间内所有结点最近公共祖先的深度。

## 数据点 $1\sim 2$

???+ note "题目描述"

    这一档保证 $n,q\leq 300$。

??? tip "Hint"

    预处理任意连续区间的权值和与最近公共祖先深度。

??? success "解法"

    对每次询问枚举 $l\leq a\leq b\leq r$，检查区间权值和是否达到 $k$，并更新最近公共祖先的最大深度。

    时间复杂度为 $\mathcal{O}(n^2+qn^2)$，空间复杂度为 $\mathcal{O}(n^2)$。

## 数据点 $3\sim 5$

???+ note "题目描述"

    这一档保证 $n,q\leq 2000$。

??? tip "Hint"

    二分答案深度 $d$。

??? success "解法"

    最近公共祖先深度至少为 $d$，等价于整个区间位于某个深度为 $d$ 的结点子树中。枚举这一深度的结点，计算其子树编号区间与 $[l,r]$ 的交集权值和，判断是否至少为 $k$。

    一次判定需要 $\mathcal{O}(n)$，每次询问需要 $\mathcal{O}(n\log n)$。

## 数据点 $6\sim 9$

???+ note "题目描述"

    这一档保证树是一条链。

??? tip "Hint"

    区间 $[a,b]$ 的最近公共祖先就是结点 $a$。

??? success "解法"

    固定左端点 $a$ 后，最大的可用权值和为 $W(a,r)$。因此需要找到满足 $W(a,r)\geq k$ 的最大 $a$。权值为正，前缀和严格递增，可以二分该位置。

    每次询问的时间复杂度为 $\mathcal{O}(\log n)$。

## 数据点 $10\sim 13$

???+ note "题目描述"

    这一档保证 $k=W(l,r)$。

??? tip "Hint"

    权值均为正，只有完整区间的权值和能够达到 $k$。

??? success "解法"

    答案就是结点 $l,l+1,\ldots,r$ 的最近公共祖先深度。由于编号来自深度优先遍历，这个最近公共祖先等于 $\operatorname{LCA}(l,r)$，使用倍增即可回答。

## 数据点 $14\sim 20$

???+ note "题目描述"

    这一档保证 $k\leq\min_{i=l}^{r}w_i$。

??? tip "Hint"

    任意单点区间都满足权值条件。

??? success "解法"

    单点区间 $[i,i]$ 的最近公共祖先就是结点 $i$，答案转化为 $[l,r]$ 中结点深度的最大值。对深度数组建立稀疏表或线段树即可。

## 正解

???+ note "题目描述"

    对固定深度 $d$，需要快速判断是否存在可行区间。

??? tip "Hint"

    同一深度的子树编号区间互不相交，并且按照左右端点同时递增的顺序排列。

??? success "判定条件"

    固定深度 $d$，考虑深度为 $d$ 的结点 $u$，其子树编号区间记为 $I_u$。

    若一个合法区间的最近公共祖先深度至少为 $d$，那么该区间一定完整位于某个 $I_u$ 中。反过来，$I_u\cap[l,r]$ 仍然是连续区间；若这个交集的权值和至少为 $k$，由于权值均为正，可以选择交集中的一段前缀使权值和达到 $k$。

    因此，深度 $d$ 可行，当且仅当存在一个深度为 $d$ 的结点，使其子树与询问区间的交集权值和至少为 $k$。

??? success "快速判定"

    与 $[l,r]$ 相交的同深度子树构成一个连续段。第一棵与最后一棵子树可能只被截取一部分，中间子树一定完整包含于 $[l,r]$。

    使用权值前缀和计算两个边界交集。对每个深度的完整子树权值建立稀疏表，中间部分直接查询最大值。两次二分找到相交子树段，一次判定的时间复杂度为 $\mathcal{O}(\log n)$。

??? success "二分答案"

    若深度 $d$ 可行，那么所有小于 $d$ 的深度也可行。因此可以二分最大的可行深度。预处理所有子树右端点、结点深度、权值前缀和，以及每个深度对应的稀疏表。

??? success "正确性"

    判定条件已经证明了深度 $d$ 可行的充要性。深度为 $d$ 的子树一定包含在某个深度为 $d-1$ 的子树中，所以可行深度构成前缀，二分得到的最大可行深度正是答案。

??? abstract "复杂度分析"

    预处理时间与空间复杂度均为 $\mathcal{O}(n\log n)$。每次询问进行 $\mathcal{O}(\log n)$ 次深度判定，每次判定需要 $\mathcal{O}(\log n)$，故单次询问的时间复杂度为 $\mathcal{O}(\log^2 n)$。
