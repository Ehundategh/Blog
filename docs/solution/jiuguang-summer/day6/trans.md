# 万山舆共渡

## 题意简述

给定一棵 $n$ 个点的带权树和 $m$ 条运输计划，每条计划沿树上唯一简单路径运输。可以选择一条边令其权值变为 $0$，求所有计划的最大路径长度最小是多少。

## Hint

二分最终答案 $Mid$。只有原路径长度大于 $Mid$ 的计划会提出限制：被清零的那条边必须同时在这些计划路径上，并且边权至少能够弥补它们超过 $Mid$ 的部分。

??? note "提示"
    对所有长度大于 $Mid$ 的路径做树上差分。若某条边被这些路径全部覆盖，且边权不小于最大路径长度与 $Mid$ 的差，则 $Mid$ 可行。

## 解法

先用 LCA 求出每条计划的路径长度。二分答案 $Mid$。

对所有长度大于 $Mid$ 的计划，将其路径在树上差分加一。设这些计划数量为 $Cnt$，原最大路径长度为 $MaxDis$。若存在一条边满足：

1. 差分统计值等于 $Cnt$，即它被所有超限路径经过；
2. 这条边权值 $w\ge MaxDis-Mid$；

则把这条边权值变为 $0$ 后，所有超限路径都能被压到 $Mid$ 以内，答案可行。

否则，无论选择哪条边，都不能同时处理所有超限计划，答案不可行。

## 复杂度

LCA 预处理为 $\mathcal{O}(n\log n)$。每次 check 为 $\mathcal{O}(n+m)$，二分答案后总复杂度为 $\mathcal{O}((n+m)\log V+n\log n)$。
