# 概率论初步

概率论研究随机试验中的规律。这里从样本空间与事件开始，依次讨论条件概率、独立性、全概率公式与 Bayes 公式，再引入随机变量、期望、方差与期望递推。

本节沿用课件中的记号：样本空间记为 $\Omega$，事件记为 $A,B$，概率记为 $P(A)$，随机变量记为 $X,Y$，期望与方差分别记为 $E(X),D(X)$。
