## 题目简述

### 鹧鸪天

给定相邻计数序列，求有多少个二进制灯阵列满足每个位置及其相邻位置的点亮数量。

### 雨霖铃

在无向图中构造一棵生成树，要求恰好选出 $k$ 条指定类型的边。

### 金缕曲

在有向图上从起点出发，可重复经过边并获得递减收益，求最大总收益。

### 蝶恋花

维护区间加、区间取最小值、区间和、区间最大值与区间历史最大值。
