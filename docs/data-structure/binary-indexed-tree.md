# 树状数组

在算法竞赛中，我们经常需要维护一个序列，并支持单点修改与前缀和查询。线段树可以处理更一般的区间问题，但在只需要单点修改、区间查询的场景下，树状数组的代码更短，空间也更轻。

树状数组的核心思想是利用正整数的二进制分解。对于任意正整数 $x$，它可以被唯一分解为若干个 $2$ 的幂之和。树状数组中的位置 $x$ 并不维护任意区间，而是维护区间 $(x-\operatorname{lowbit}(x),x]$ 的权值和。

这里 $\operatorname{lowbit}(x)$ 表示 $x$ 的二进制表示中最低位的 $1$ 及其后面的 $0$ 构成的数值：

$$
\operatorname{lowbit}(x)=x\&(-x).
$$

## 基本操作

树状数组的基本操作非常紧凑。在具体实现中，我们约定：

- $\operatorname{lowbit}(x)$ 利用补码性质快速提取最低位。
- $\operatorname{Modify}(x,\operatorname{Val})$ 表示单点修改。当位置 $x$ 增加 $\operatorname{Val}$ 时，需要自底向上更新所有包含 $x$ 的树状数组区间。这些区间的编号可以通过不断加上 $\operatorname{lowbit}(x)$ 得到。
- $\operatorname{Query}(x)$ 表示前缀和查询。求序列前缀 $[1,x]$ 的权值和时，我们自顶向下累加区间和，通过不断减去 $\operatorname{lowbit}(x)$ 跳过已经统计的部分。

核心代码如下。

```cpp
inline int lowbit(int x){
    return x&-x;
}

void Modify(int x,int Val){
    for(;x<=n;x+=lowbit(x)) C[x]+=Val;
}

int Query(int x){
    int Ret=0;
    for(;x>0;x-=lowbit(x)) Ret+=C[x];
    return Ret;
}
```

如果要求区间 $[l,r]$ 的和，只需要计算

$$
\operatorname{Query}(r)-\operatorname{Query}(l-1).
$$

因此单点修改和区间查询的时间复杂度都是 $\mathcal{O}(\log n)$，空间复杂度为 $\mathcal{O}(n)$。

## 离线二维数点

树状数组的一个常见用法，是把二维数点问题中的一维离线掉，只维护剩下一维的前缀统计。

以「商路照影」为例。我们可以把树上的子树查询转化到 DFS 序上：每个节点 $u$ 的子树对应连续区间 $[\operatorname{In}(u),\operatorname{Out}(u)]$。如果还需要限制权值小于某个 $w$，问题就变成了在一个 DFS 序区间内统计权值位于 $[1,w-1]$ 的点数。

考虑把所有查询拆成两个前缀查询。对于区间 $[l,r]$ 内权值不超过 $v$ 的点数，可以写成

$$
F(r,v)-F(l-1,v),
$$

其中 $F(p,v)$ 表示 DFS 序前 $p$ 个位置中，权值不超过 $v$ 的点数。

于是我们可以按照 DFS 序从左到右扫描节点，并用树状数组维护当前已经扫描到的节点权值频数。扫描到某个位置 $p$ 时，所有右端点为 $p$ 的询问都可以通过一次树状数组前缀查询得到答案。

这类做法的本质是：把一个维度变成扫描顺序，把另一个维度交给树状数组维护。这样一来，查询和修改都只需要 $\mathcal{O}(\log n)$ 的时间。

## 与线段树合并的关系

有关「商路照影」基于线段树合并的在线解法，可以参考专题：[线段树合并](segment-tree/merge.md)。

树状数组的离线做法并不替代线段树合并的所有场景。它要求查询可以按某个维度排序，并且被维护的另一维具有可前缀化的统计结构。若信息需要在树上回溯时动态合并，或者每个节点维护的是更复杂的桶与最值，线段树合并仍然更自然。

在可以离线的二维数点场景下，树状数组常常能把空间复杂度从动态开点线段树的 $\mathcal{O}(n\log W)$ 降到 $\mathcal{O}(n)$，实现也更轻。关于「商路照影」题目的完整题解，可以参考：[GSOI 2026 商路照影](../solution/jiuguang-summer/day2/trade.md)。
